**Is it free?**
Yes. The technical check and the full AI answer check on [qqq.ee](https://qqq.ee/en/ai-visibility-checker/) are both free. No account or API key is needed.

**Why is there no overall score?**
Crawler access, mentions in AI answers and citations of your site measure different things. A single number would hide which one needs work, so the checker reports them separately.

**What does "Daily check limit reached" mean?**
qqq.ee limits how many free technical checks run per day. The plugin keeps showing your last result and reuses a result for six hours, so opening the dashboard does not use a check.

**Does the plugin run the AI answer check?**
No. Asking ChatGPT, Gemini, Perplexity and Claude takes real model calls, so that check runs on qqq.ee. Once a report exists, the plugin shows its numbers and links to it.

**What is checked for AI crawlers?**
GPTBot, OAI-SearchBot, ChatGPT-User, ClaudeBot, PerplexityBot, Google-Extended and other AI user agents in your robots.txt, plus whether the server answers them. See the [AI search optimization guide](https://qqq.ee/en/ai-search-optimization/) for what to do with the results.
